# Portfolio Développeur Web

Portfolio professionnel moderne et responsive pour développeur web.

## 🌟 Fonctionnalités

### Navigation
- **6 pages complètes** : Accueil, Compétences, Projets, Expérience, Contact, CV
- **Animation livre** : Transitions fluides avec effet de page qui tourne
- **Sidebar fixe** (desktop) avec navigation et liens sociaux
- **Menu hamburger** (mobile) avec drawer animé
- **Navigation clavier** : Touches fléchées (←/→) ou touches numériques (1-6) pour naviguer entre les pages

### Langues & Thèmes
- **Multilingue** : Français (par défaut) et Anglais
- **Mode sombre/clair** : Basculement en temps réel avec persistance

### Pages

#### 🏠 Accueil
- Photo professionnelle
- Bio courte et percutante
- Statistiques clés (expérience, projets, technologies)
- Boutons CTA vers Projets et Contact

#### 💻 Compétences
- Grilles organisées par catégorie (Frontend, Backend,Database, Tools)
- Barres de progression animées
- Icônes pour chaque catégorie

#### 📁 Projets
- Grille de cartes avec images
- Tags technologiques
- Liens GitHub et sites live
- Descriptions détaillées

#### 🎓 Expérience
- Timeline verticale professionnelle
- Réalisations par poste
- Section Formation avec diplômes
- Certifications professionnelles

#### 📧 Contact
- Formulaire de contact complet
- Informations de contact directes
- Liens réseaux sociaux
- Placeholder carte de localisation

#### 📄 CV
- Mise en page professionnelle
- Téléchargement PDF
- Impression optimisée
- Toutes les informations essentielles

## 🎨 Design

- **Style moderne et minimaliste**
- **Gradients bleu/teal** comme couleur d'accent
- **Cartes arrondies** avec ombres douces
- **Animations fluides** avec Motion (Framer Motion)
- **Responsive** : adapté mobile, tablette et desktop

## 🛠️ Technologies

- React
- TypeScript
- Tailwind CSS
- Motion (Framer Motion)
- Lucide React (icônes)
- Shadcn/ui (composants)

## 📱 Responsive

- **Desktop** : Sidebar fixe à gauche (≥1024px)
- **Tablette/Mobile** : Header avec menu hamburger
- Design adaptatif sur toutes les tailles d'écran

## 🚀 Utilisation

1. Personnalisez les informations dans chaque composant
2. Remplacez les liens sociaux et email
3. Ajoutez vos propres images de projets
4. Modifiez les compétences et expériences selon votre parcours
5. Générez un vrai PDF pour le CV téléchargeable

## 📝 Personnalisation

Les contenus sont organisés dans des objets `content` au début de chaque composant pour faciliter la traduction et la personnalisation.

## 🌐 Langues disponibles

- Français (fr) - Par défaut
- Anglais (en)

Pour ajouter une langue, ajoutez les traductions dans les objets `content` de chaque composant.
